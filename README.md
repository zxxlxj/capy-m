# MANIA

连接你自行部署的媒体服务，在 CapyPlayer 中浏览和播放。

在 CapyPlayer 的组件页面添加以下地址：

```text
https://raw.githubusercontent.com/zxxlxj/capy-m/main/docs/plugin-platform/examples/mania/mania.js
```

填写自部署服务器地址和 API，选择播放账号。使用备用账号时，有多个账号则填写对应的账号名称。

打开「电影」或「电视剧」浏览，也可以通过「查找影片」按片名查找。
